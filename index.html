Routine changes today

  • Easy Apply is no longer a <button>. It is now a[aria-label="Easy Apply to this job"]. The documented selector (button with aria-label starting "Easy Apply to") matches nothing.
  • The apply modal lives in a shadow root on a plain <div> host — div[role="dialog"] and document.querySelectorAll('select') both miss it. Walk open shadow roots to reach the form.
  • JS .click() silently no-ops on the Easy Apply anchor. Real coordinate clicks are required, and the first click after hydration often pops a "Save this application?" overlay that must be dismissed (X at 843,216) before the form is usable.
  • Screenshot ↔ CSS pixel scale is 0.8056 (1450 px screenshot / 1800 px viewport). Button rects read out of the shadow root must be multiplied by that factor before clicking, otherwise Submit lands off-screen.
  • Some short-answer fields reject long text with "Please enter a valid answer" — Mondia's Vue/Node question accepted 53 chars after rejecting 172. Keep screening answers terse.
  • Selects inside the modal are real <select> elements and respond to the native value setter plus input/change events with composed:true.
