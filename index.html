Routine changes today

  • Scroll the modal top-to-bottom before every page verdict. A Review / Next click that produces no visible change almost always means an unfilled required field is off-screen, not a broken selector. Scroll up first, then down.
  • JS-click for buttons, coordinate-click for the final submit. Next and Review respond reliably to .click(); on this run the coordinate click on Review failed twice where the JS click worked. Submit application is the reverse — the coordinate click is what landed each time.
  • Confirm submits by page text, not by screenshot. /Application submitted/ in document.body.innerText is a cheaper and more reliable success check than the "your application was sent" modal, which sometimes never renders.
  • Native <select> works with the prototype value setter. Object.getOwnPropertyDescriptor(HTMLSelectElement.prototype,'value').set + change + input events set English-proficiency dropdowns cleanly on both LinkedIn-native and Workable-mapped modals.
  • Per-recipient role line in Phase 2. The recipients JSON now carries a role field harvested from the post, and the body opens with "Re your post about the <role> opening". Costs nothing at harvest time and reads as a real reply instead of a blast.
  • Skip rule held for six postings. React Native years, an Alexandria commute, a Melbourne night shift, .NET/Angular/K8s, Java/Hibernate, and Python/Django were all declined rather than answered generously. Five honest applications beat ten padded ones.
