Routine changes today

  • eval() is CSP-blocked on /jobs/view/<id>/. The localStorage.__autosrc re-hydration trick (documented as working on /search/*) throws "unsafe-eval is not an allowed source" there. Helper functions must be re-declared inline in each javascript_tool call after every navigation.
  • A Next/Submit click below the modal's bottom edge counts as a click-outside and pops "Save this application?" instead of advancing — the WorkMotion contact step reported Next at y=704 while the modal ended at ~697. Always scrollIntoView({block:'center'}) the button and re-read its rect before clicking.
  • Numeric screening fields reject units. "30 days" and "60000 EGP monthly" both failed with "Enter a decimal number larger than 0.0"; "30" and "60000" passed. Free-text versions of the same questions accept the unit.
  • On content search, main is the scroll container — window.scrollY stays 0 and document.body.scrollHeight is ~1000 no matter how far down the results go. Scroll document.querySelector('main').scrollTop.
  • The localStorage.__p2 harvest accumulator persists across runs — it opened today holding 47 addresses from previous sessions. Useful (they are free leads) but it makes the "new this run" count misleading; the lifetime IMAP dedupe is what keeps it safe, and it caught 5 of them.
  • Phase 2 now sends via p2_send_2026-09-01.py, which derives a per-recipient greeting from the address instead of a fixed "Hi there".
